# Personal website

A personal site that presents Fahmi as an engineer and holds his writing. It is read by visitors,
written by one person, and published as static files.

## Language

**Post**:
A dated piece of writing in the `writing` collection, addressed to strangers rather than to
future-me notes.
_Avoid_: Article, blog entry, note

**Project**:
A curated entry describing one piece of built work, chosen by hand for what it demonstrates.
_Avoid_: Repo, repository, portfolio item

**Archive**:
The link out to the full GitHub repository list. Not part of this site's content.
_Avoid_: All projects, other projects

**Tag**:
A lowercase topic label on a post, used only for grouping posts. Not a taxonomy.
_Avoid_: Category, topic, keyword

**Draft**:
A post present in the repo but excluded from the site, RSS, and sitemap until `draft: false`.
_Avoid_: Unpublished, WIP

**Portrait**:
The photo on the About page. Reserved, not present at launch.
_Avoid_: Avatar, profile picture, photo
